# Fabbit

Карманная платформа на ПЛИС со сменными аппаратными профилями. Профиль меняет
схему, а не программу.

Статус: инициализация. Кода нет, платы нет.

## Структура

```
gateware/   ПЛИС
firmware/   микроконтроллер
profiles/   содержимое карты памяти
hardware/   платы и корпус
host/       утилиты для ПК
journal/    дневник
```
