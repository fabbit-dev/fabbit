# Fabbit

Карманная платформа на ПЛИС. Сменный профиль меняет схему, а не программу.

```
gateware/   ПЛИС
firmware/   микроконтроллер
profiles/   содержимое карты памяти
hardware/   платы и корпус
host/       утилиты для ПК
journal/    дневник
```

Как работать с репозиторием: [CONTRIBUTING.md](CONTRIBUTING.md).
