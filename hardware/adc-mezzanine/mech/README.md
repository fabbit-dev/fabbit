# Механика мезонина (осциллограф)

Плата 60 × 15 × 1,6 мм: x −30…30, y −101…−86. Координаты и импорт как у главной
платы: `hardware/mainboard/mech/README.md`.

F смотрит на главную плату: входы, реле, АЦП, разъём. B смотрит на крышку, зазор 1,9 мм.

| Что | Где (мм) |
|---|---|
| SMA CH1 / CH2, торцевые | верхний край, x −8 / +8 |
| Разъём ERM8-030-02.0, ответный | x −14,5…16,5, y −91,8…−85,2 |
| Винты M2.5 к стойкам, отверстия Ø2,7 | (−26; −88,2), (26; −88,2) |
| Входы, реле 1 МОм / 50 Ом, экран | x −16…16, y −100,5…−92 |
| AD9288, ADS1220, ID-EEPROM | x 17…29, y −100…−91,5 |

Слот общий для мезонинов: 60 контактов, до 24 линий данных, I2C, ID-EEPROM.
