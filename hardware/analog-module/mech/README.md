# Механика модуля аналога

Плата 73 × 37,3 × 1,5 мм: x −36,5…36,5, y −124…−86,7. Угол x > 20, y < −100 вырезан:
под ним антенна ESP32-C5 главной платы. Координаты и импорт как у главной платы:
`hardware/mainboard/mech/README.md`.

F смотрит на главную плату, B на крышку. Стек 9,0 мм от B главной платы до F модуля.
Весь аналоговый тракт стоит на модуле, вход 1 МОм через разъём не идёт.

| Что | Где (мм) |
|---|---|
| SMA CH1 / CH2 / GEN, Lineyi SMA-KE-L12.4 (запасной Molex 73251-1150), торцевые | верхний край y −124, x −19 / −7 / 5 |
| Разъём BergStak 61083-081402LF, ответный | x −18,9…18,9, y −93,8…−87, F |
| Винты M2.5 к стойкам, отверстия Ø2,7 | (−30; −89,2), (24; −89,2), (−26; −120,5), (14; −120,5) |

## Высоты деталей

| Сторона | Где | Высота |
|---|---|---|
| F | весь модуль, кроме разъёма, стоек и места над колесом | ≤ 5,65: реле HFD4/3-LSR, дроссели TPS65131 3,0 |
| F над колесом | x −36,5…−30,5, y −124…−108 | ≤ 4,4 |
| B | весь модуль, головки винтов тоже | ≤ 1,6, до крышки 0,4 |

Под модулем на главной плате детали до 3,0 мм, до реле остаётся 0,35.

SMA без гайки: фланец 9,52 упирается в полку корпуса изнутри, резьба выходит на 5,9 мм.
Чертежа SMA-KE-L12.4 нет: геометрия в модели по Molex 73251-1150, Lineyi сверить на образце.
Ножки Molex охватывают плату 1,57 мм (SD-73251-115, л. 1), модуль 1,5 мм: посадку сверить на образце.
Положение оси относительно платы по чертежу Molex не однозначно: сверить по образцу.
