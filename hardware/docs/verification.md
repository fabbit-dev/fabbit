# Проверка BOM v2 по даташитам

Дата: 2026-10-03. Стадия выбора компонентов, до схемы. Страницы указаны по нумерации
PDF (1 = первая страница файла). «~» означает значение с графика typical при 25 °C,
а не из таблицы. «н/п» означает «не подтверждено»: в документе этого нет или документ
не найден.

Здесь не построчная проверка платы. Для схемы каждая деталь ещё раз проходит чек-лист
`.claude/rules/hardware.md` и попадает в `hardware/<плата>/VERIFY.md`.

Источники ADI (HMCAD1511, ADF4351, AD974x, ADG16xx) взяты с зеркала datasheet4u:
analog.com с этой машины PDF не отдаёт. Ревизии совпадают с указанными на analog.com.
Перед заказом сверить ревизии на analog.com. GL850G Rev 1.07 и FT232H v1.82 старые,
актуальные ревизии не скачались: сверить перед схемой.
