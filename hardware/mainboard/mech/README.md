# Механика главной платы

Источник: `hardware/case/fabbit_case.FCStd`.

Координаты общие для прибора и мезонина. Ноль: центр по ширине, низ корпуса.
KiCad: x = X прибора, y = −Z. Плата x −41…41, y −148…−2, толщина 1,6 мм.
F смотрит на экран и кнопки, B на крышку.

## Импорт в KiCad

DXF в git нет, они лежат в GitHub Releases. Контур и расстановка уже есть в
`fabbit_mainboard.kicad_pcb`. Повторный импорт: `File → Import → Graphics…`, мм,
позиция (0, 0):

| Файл | Слой |
|---|---|
| `fabbit_mainboard_edge_cuts.dxf` | Edge.Cuts |
| `fabbit_mainboard_front_placement.dxf` | F.Fab |
| `fabbit_mainboard_back_placement.dxf` | B.Fab |

Детали сквозь плату (`side = edge`: HDMI, колесо, выключатель) есть в обоих placement.
Отверстия H1…H8: `MountingHole_2.2mm_M2` по `fabbit_mainboard_placement.csv`.
H1…H6 держат корпус, H7…H8 держат мезонин.

## Что задаёт корпус

| Что | Где (мм) | Сторона, примечание |
|---|---|---|
| USB-C mid-mount, вырез | x −4,6…4,6, y −7…−2 | заподлицо с низом |
| HDMI Type A mid-mount, вырез | x −30,1…−14,9, y −11,8…−2 | над B ~2,4 мм, выше аккумулятор |
| microSD push-push | x 16…28, низ | F, прорезь x 14,5…29,5 |
| Колесо Ø12, вырез | x −41…−34,9, y −122,5…−109,5 | выступ в левый бок 3,3 мм |
| Выключатель | левый край, y −105…−94 | паз в корпусе |
| Гребёнки A / PWR / B | верхний край | B, угловые 2×10 / 2×2 / 2×10, Y ≈ 10 |
| SO-DIMM угловой H=4,0 | y −58,5…−52 | B, модуль i9+ до y −85, теплосъём на крышку |
| Разъём мезонина | x −8…20, y −90,5…−86,5 | B, стек 9,2 мм |
| Экран | x −35…35, y −141,5…−90,5 | F, шлейф на F |
| Кнопки | см. CSV | F, высота ≤ 2,4 мм |
| ESP32-C3-MINI-1 | x 24…40,6, y −35,2…−22 | F, под антенной без меди |

Высоты по толщине: CSV, `Y_from_mm` / `Y_to_mm`. Толщина i9+ пока допущение.
