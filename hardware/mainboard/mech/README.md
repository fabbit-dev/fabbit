# Механика главной платы

Источник: `hardware/case/fabbit_case.FCStd`.

Координаты общие для прибора и мезонина. Ноль: центр по ширине, низ корпуса.
KiCad: x = X прибора, y = −Z. Плата x −41…41, y −148…−2, толщина 1,6 мм.
F смотрит на экран и кнопки, B на крышку.

## Импорт в KiCad

DXF в git нет, они лежат в GitHub Releases. Контур и расстановка уже есть в
`fabbit_mainboard.kicad_pcb`. В `.kicad_pcb` начало сдвинуто: x = X + 100,
y = 200 − Z. Повторный импорт: `File → Import → Graphics…`, мм, позиция (100, 200):

| Файл | Слой |
|---|---|
| `fabbit_mainboard_edge_cuts.dxf` | Edge.Cuts |
| `fabbit_mainboard_front_placement.dxf` | F.Fab |
| `fabbit_mainboard_back_placement.dxf` | B.Fab |

Детали сквозь плату (`side = edge`: HDMI, колесо, выключатель) есть в обоих placement.
Отверстия по `fabbit_mainboard_placement.csv`. H1…H6 держат корпус: `MountingHole_2.2mm_M2`.
H7…H8 держат мезонин: SMD-стойки M2.5 H9 Würth 9774090151 на B, отверстие Ø3,7,
y −88,2, чтобы отверстие не заходило под экран.
