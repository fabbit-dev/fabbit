# Механика главной платы

Источник: `hardware/case/fabbit_case.FCStd`.

Координаты общие для прибора и мезонина. Ноль: центр по ширине, низ корпуса.
KiCad: x = X прибора, y = −Z. Плата x −42,2…42,2, y −147,8…−2,2, толщина 1,6 мм.
F смотрит на экран и кнопки, B на крышку.

## Импорт в KiCad

DXF в git нет, они лежат в GitHub Releases. В `.kicad_pcb` начало сдвинуто: x = X + 100,
y = 200 − Z. Импорт: `File → Import → Graphics…`, мм, позиция (100, 200):

| Файл | Слой |
|---|---|
| `fabbit_mainboard_edge_cuts.dxf` | Edge.Cuts |
| `fabbit_mainboard_front_placement.dxf` | F.Fab |
| `fabbit_mainboard_back_placement.dxf` | B.Fab |

Детали в вырезах платы (`side = edge`: HDMI, кнопка питания, динамик) есть в обоих placement.
Отверстия по `fabbit_mainboard_placement.csv`. H1…H9 держат корпус: `MountingHole_2.2mm_M2`.
H10, H11 держат мезонин: SMD-стойки M2.5 H9 Würth 9774090151 на B, отверстие Ø3,7.
Отверстие заходит под экран на 0,55 мм: на F под ним ничего нет.

Контур и расстановка в `fabbit_mainboard.kicad_pcb` ещё под прежний корпус 88 мм: обновить по этим файлам.
