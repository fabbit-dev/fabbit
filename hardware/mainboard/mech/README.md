# Механика главной платы

Источник: `hardware/case/fabbit_case.FCStd`.

Координаты общие для прибора и модуля аналога. Ноль: центр по ширине, низ корпуса.
KiCad: x = X прибора, y = −Z. Плата x −42,2…42,2, y −147,8…−2,2, толщина 1,5 мм.
F смотрит на экран и кнопки, B на крышку.

## Импорт в KiCad

DXF в git нет, они лежат в GitHub Releases. В `.kicad_pcb` начало сдвинуто: x = X + 100,
y = 200 − Z. Импорт: `File → Import → Graphics…`, мм, позиция (100, 200):

| Файл | Слой |
|---|---|
| `fabbit_mainboard_edge_cuts.dxf` | Edge.Cuts |
| `fabbit_mainboard_front_placement.dxf` | F.Fab |
| `fabbit_mainboard_back_placement.dxf` | B.Fab |

Детали в вырезах платы (`side = edge`: HDMI, динамик) есть в обоих placement.
Отверстия по `fabbit_mainboard_placement.csv`. H1…H8 держат корпус: `MountingHole_2.2mm_M2`.
H9…H12 держат модуль аналога: SMD-стойки M2.5 H9 Würth 9774090151 на B, отверстие Ø3,7.
Отверстия H9…H12 под экраном (H9, H10 на 0,55 мм): на F там ничего нет.
Контур платы с отверстиями: `fabbit_mainboard_outline.svg`.

В `fabbit_mainboard.kicad_pcb` контур из `fabbit_mainboard_edge_cuts.dxf` без кругов H1…H12:
отверстия дают футпринты. Заглушки `MECH_*` из `fabbit_mech.pretty` стоят по CSV, обозначения
и сверка в `../VERIFY.md`.

## Зоны узлов (высота над платой)

| Зона | Где | Высота |
|---|---|---|
| F | вся сторона, кроме экрана и кнопок | ≤ 2,2 |
| F у USB-C: CH32H417QEU6 (QFN128 12,3 × 12,3 × 0,85) и обвязка | x 15…40, y −35…−19, MCU в центре (27,5; −27) | ≤ 1,5 |
| B под банкой | y −43,2…−19,5 | ≤ 2,0 |
| B под модулем i9+ | y −84…−48,6 | ≤ 3,9 |
| B под модулем аналога | контур модуля, кроме разъёма и стоек | ≤ 3,0: над ними реле модуля 5,65, зазор 0,35 |
| B под модулем: лаб. БП (TPS55289, дроссель 3,0) | x −14…14, y −113,5…−100 | ≤ 3,0 |
| B под выемкой SMA | x −26…12, y −136,9…−125,6 | ≤ 1,7 |
| B у порта A: TLV3501, BAV199, ESDCAN05 | x −36,5…−15, y −136,6…−123,2 | ≤ 1,5 |
| B у порта B и MIPI20: SN74LXC1T45, SN74LXC8T245, TPD4E1U06 | x 12…34, y −136,6…−129 | ≤ 1,5 |
| B вверху, до штырей гнёзд | y −137,1…−127,7 | ≤ 4,2 |

Высоты по толщине: CSV, `Y_from_mm` / `Y_to_mm`. Толщина i9+ снизу и смысл «5,2» у гнезда TE
пока допущения: сверить по STEP или замеру. Дроссели SPM6530T 3,0 мм (BQ25798, TPS61023)
на F не встают: там ≤ 2,2.
