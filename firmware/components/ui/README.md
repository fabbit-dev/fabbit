# ui

Графика меню для плоскости golden (`docs/bus-protocol.md`, «Плоскость меню»): кадр 640×480 по 4 бита на пиксель в памяти супервизора, примитивы, текст UTF-8 со сглаживанием, битмапы. Изменённые области копятся и уходят в плоскость через порт (`ui_port_t`). Чистый C11 без ОС: один код для ESP32-S3, CH32H417 и `ports/pcsim`.

- `assets/font_*.c`: JetBrains Mono Medium и Bold, 15–24 пикселя, латиница, кириллица, `·«»—…×№▲▼◀▶←→✓●°µΩ±`. 4 бита альфы. Шрифт под SIL OFL 1.1, текст лицензии в `assets/LICENSE-OFL.txt`.
- `assets/bitmaps.c`: знак, логотип, 35 иконок 16×16 и 10 анимаций бренд-кита Fabbit, 1 бит.

Файлы `assets/` сгенерированы, руками не правятся.
